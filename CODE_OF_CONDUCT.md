# Code of Conduct

Participants in the Cynos projects are expected to be respectful, constructive,
and inclusive.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, deliberate disruption, publishing private information, and conduct that
would make a reasonable contributor feel unsafe.

Maintainers may remove comments, close discussions, or restrict participation
when necessary to keep the project healthy. Report concerns privately through
the security/reporting contact described in `SECURITY.md`; do not include
sensitive personal information in a public issue.
